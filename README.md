# ThriveJolt

ThriveJolt enables Real-Time Processing of high-volume data streams through distributed High-Performance computing with dynamic Auto-Scaling Agent clusters.

The key benefits of using ThriveJolt include:

- ThriveJolt enables Real-Time Processing of
- high-volume data streams through distributed
- High-Performance computing with dynamic Auto-Scaling

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ThriveJolt.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ThriveJolt is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
